# Что нужно отрисовать для существующего функционала

Ниже — только функции, которые реализованы в проекте и должны быть доступны
в production по `EXISTING_BUSINESS_LOGIC_AND_UI_INTEGRATION.md`.

Не включены намеренно скрытые или неподтверждённые для production функции:
оплата/Plus, referrals, уведомления, внутренний apply-flow, watch-search alerts
и т. п.

## P0 — рекрутерский кабинет

Для этой части есть работающая логика и Firebase-репозитории, но в исходном
«новом дизайне» её не было. Нужны макеты всех перечисленных экранов и состояний.

### 1. Вход в recruiter mode

- Экран активации recruiter mode.
- Состояния: загрузка, ошибка, успешная активация.

### 2. Главная recruiter dashboard

- Сводные показатели: вакансии, кандидаты, действия, требующие внимания.
- Пустое состояние, загрузка и ошибка с повторной попыткой.

### 3. Вакансии рекрутера

- Список вакансий: draft, published, closed.
- Создание вакансии.
- Редактирование вакансии.
- Закрытие/публикация вакансии.
- Подтверждение удаления вакансии.

### 4. ATS-пайплайн вакансии

- Выбор вакансии для просмотра пайплайна.
- Список или канбан кандидатов по стадиям.
- Перенос кандидата между стадиями.
- Добавление заметки к кандидату в рамках вакансии.
- Удаление кандидата из пайплайна с подтверждением.

### 5. База кандидатов

- Список кандидатов.
- Поиск и фильтры кандидатов.
- Карточка кандидата.
- Создание кандидата.
- Редактирование кандидата.
- Подтверждение удаления кандидата.

### 6. Компании и команда

- Список компаний.
- Создание и редактирование компании.
- Экран/модалка участников компании.
- Управление ролью участника и удаление участника.
- Подтверждение удаления компании.

### 7. Приглашение в команду

- Создание приглашения.
- Экран с invite-link и действием «скопировать/поделиться».
- Pending-приглашения.
- Ошибка создания/копирования ссылки.

### 8. Принятие приглашения

- Пользователь не авторизован.
- Невалидная, использованная или просроченная ссылка.
- Подтверждение принятия приглашения.
- Успешное вступление в команду.
- Ошибка принятия приглашения.

## P1 — новые сценарии внутри job seeker части

Основные страницы уже были в новом дизайне. Но для следующих добавленных
production-сценариев нет соответствующих макетов.

### 9. Трекер откликов

- Модалка создания отклика.
- Модалка редактирования отклика.
- Добавление заметки.
- Настройка даты follow-up.
- Подтверждение удаления отклика.
- Ошибки сохранения и валидация полей.

### 10. Saved / wishlist

- Ручное добавление вакансии в wishlist.
- Редактирование вакансии из wishlist.
- Подтверждение удаления.
- Перенос вакансии из wishlist в applications.
- Состояние частичной ошибки: отклик создан, но элемент wishlist не удалился.

### 11. Career Hub — администрирование ссылок

- Включение режима редактирования для admin.
- Добавление ссылки.
- Редактирование ссылки.
- Подтверждение удаления ссылки.
- Состояния загрузки, ошибки и успешного сохранения.

## Общие компоненты, которые нужны в дизайне

- Единый loading state.
- Единый empty state.
- Единый error state с Retry.
- Единая destructive-confirmation modal.
- Единый form modal: заголовок, поля, валидация, cancel/submit/loading.
- Единые toast/inline сообщения об успехе и ошибке.

## Проверка перед production

Эти функции работают в demo mode. Для live-production дополнительно должны быть
настроены Firebase env, Auth providers, Firestore/Storage rules и нужные индексы.
